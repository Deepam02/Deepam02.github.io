Multi-agent isn't a buzzword when each agent runs in its own Kubernetes pod, spawned on demand, wired to live Jira queues and real telecom alarm systems. I built the whole thing solo — Terraform, orchestration, integrations, and agent logic. Three templates shipped and running.

  • Ticket-to-pod pipeline: Jira webhook → spawn → classify → AgentMail escalation
  • L1/L2 triage with alarm correlator and change management lookups
  • Svix signature verification + atomic SQL state transitions on all reply handling
  • Thread-ID routing keeps agents contextual across multi-turn conversations

Telcos fire the same SMS at 100,000 people and call it personalisation. AutoCLM replaces that with continuous 1:1 AI conversations — each customer on their own arc, planned by a Journey Agent, executed by Stella via WhatsApp. I designed the architecture and shipped the full-stack demo.

  • Blueprint layer: human strategy, tone guardrails, offer limits per segment
  • Journey Agent runs continuously — per-customer engagement arc across 100k+ base
  • Stella executes 1:1 WhatsApp dialogues without hallucinating plan prices
  • Team dashboard: Morning Briefing, Cohort Live View, Simulation Sandbox

"Close enough" doesn't cut it when an AI quotes plan prices to real customers. I scrapped v1 and rebuilt with four content zones, hybrid retrieval with RRF fusion, Cohere reranking, and LLM-generated chunk labels — so what the model retrieves is actually what it needs.

  • Four zones: images, URLs, structured knowledge, unstructured FAQs
  • Dense + BM25 sparse retrieval fused with Reciprocal Rank Fusion
  • Cohere rerank-v3.5 via OpenRouter as final relevance pass
  • Soft deletes, approval loops, full audit trail — because this is production
